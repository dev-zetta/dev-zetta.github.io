# Gabriel Max — Engineering Portfolio

Source for [dev-zetta.github.io](https://dev-zetta.github.io/), a versioned portfolio built from public GitHub repositories with commit-level contribution evidence.

The site deliberately excludes private repositories, untouched forks, and this self-referential portfolio repository. That final operational exception prevents each generated inventory commit from recursively forcing another refresh. Project metadata is refreshed through a reviewable pull request, while the live site changes only when a SemVer release is published.

## Development

```bash
npm ci
npm run sync:github
npm run verify
```

`sync:github` reads `GH_TOKEN` or `GITHUB_TOKEN`, falling back to the authenticated `gh` CLI. See [docs/METHODOLOGY.md](docs/METHODOLOGY.md) for the inclusion rules and [CONTRIBUTING.md](CONTRIBUTING.md) for the release workflow.
